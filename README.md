# COS-201--PROGRAMMING--1
Practical exercises for COS 201 Computer Programming I
Week 3: Variables, Data Types, Expressions and Input/Output
Objectives
Declare and initialize Java variables
Use appropriate data types
Perform arithmetic calculations
Read keyboard input using Scanner
Display formatted output
Compile, test and submit Java programs using GitHub
Programs
week03/SimpleCalculator.java – Performs arithmetic calculations on two numbers
week03/AverageCalculator.java – Calculates the total and average of three scores
week03/ItemCost.java – Calculates the total cost using quantity and unit price
How to Run
Open a terminal in the week03 directory and run:

Simple Calculator javac SimpleCalculator.java java SimpleCalculator

Average Calculator javac AverageCalculator.java java AverageCalculator

Item Cost javac ItemCost.java java ItemCost
